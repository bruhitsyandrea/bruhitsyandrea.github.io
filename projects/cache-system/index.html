THE PROBLEM

The cache is full.
Who has to leave?

A cache has limited capacity. When new data needs to be stored and every slot is already occupied, the system must decide which existing entry should be evicted.

EVICTION DECISION

Which existing entry should be replaced?

The answer depends entirely on the replacement policy. FIFO, LRU, and Clock use different information to choose a victim.

REPLACEMENT POLICIES

Same cache.
Different decisions.

Each replacement policy answers the same question differently: when the cache is full, which entry should be sacrificed to make room for new data?

01
FIRST IN, FIRST OUT

FIFO

FIFO tracks insertion order. When the cache reaches capacity, the entry that has been stored the longest is evicted first.

Three replacement policies.

The cache separates key-value operations from replacement-policy behavior, allowing different eviction strategies to be implemented and compared without changing how the cache is used.

IMPLEMENTATION

Same interface.
Different internals.

I implemented the cache in C with separate modules for each replacement strategy, allowing FIFO, LRU, and Clock to provide the same cache behavior while maintaining different eviction state.

01 kvs_fifo.c

Maintains insertion order and removes the oldest cached entry when capacity is reached.

02 kvs_lru.c

Tracks access history so recently used entries remain cached while older unused entries become eviction candidates.

03 kvs_clock.c

Uses reference information and a moving position to implement the Clock replacement strategy.

WHAT I LEARNED

Small policy changes.
Different system behavior.

01

Data Structures Matter

Replacement algorithms require different metadata and bookkeeping depending on what information the policy needs.

02

Performance Has a Cost

More informed eviction decisions can require additional state updates and tracking on cache operations.

03

Design for Change

Separating cache behavior from replacement policy makes different algorithms easier to implement, compare, and reason about.
